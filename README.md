# Easy Recipe

Simple mobile apps for food recipe, using flutterbloc state management, API call using Dio, Go_router, Injection and clean architecture. 

# Tech Stack
- Flutter
- Dart
- BLoC
- Hive CE
- GetIt
- Go Router
- Dio
- Connectivity Plus
